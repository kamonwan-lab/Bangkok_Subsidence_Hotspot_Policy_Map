# Bangkok_Subsidence_Hotspot_Policy_Map

# 🗺️ Bangkok Subsidence Policy Map (Interactive Hotspot Map)

**โครงการปริญญานิพนธ์:** การวิเคราะห์แนวโน้มการทรุดตัวของแผ่นดินในกรุงเทพมหานครด้วยวิธี InSAR ร่วมกับข้อมูลการใช้น้ำบาดาล
**ภาควิชา:** วิศวกรรมโยธา คณะวิศวกรรมศาสตร์ มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรี (ปีการศึกษา 2568)

โปรเจกต์นี้คือเครื่องมือสร้างแผนที่เชิงนโยบายแบบโต้ตอบ (Interactive Web Map) ที่พัฒนาด้วย Python (Folium) เพื่อบูรณาการผลลัพธ์จากแบบจำลอง Machine Learning (Random Forest และ XGBoost) เข้ากับข้อมูลการทรุดตัวจริงจากดาวเทียม InSAR และข้อมูลทางอุทกธรณีวิทยา เพื่อใช้เป็นเครื่องมือสนับสนุนการตัดสินใจเชิงนโยบายและการเฝ้าระวังโครงสร้างพื้นฐาน

## ✨ ฟังก์ชันและคุณสมบัติหลัก (Core Features)

### 1. 📊 Dual-Model Explainability (การอธิบายผลแบบจำลองคู่)
* **Side-by-Side Comparison:** นำเสนอผลการวิเคราะห์ความสำคัญของตัวแปร (SHAP Values) จากทั้งโมเดล Random Forest (Bagging) และ XGBoost (Boosting) มาเปรียบเทียบกันแบบเคียงข้าง
* **CSS Donut Charts:** สร้างกราฟวงแหวน (Donut Chart) ด้วย Pure CSS เพื่อแสดงสัดส่วนอิทธิพลของกลุ่มตัวแปรน้ำบาดาล (Groundwater Impact) เทียบกับปัจจัยอื่นๆ 
* **Collapsible Sub-factors:** ระบบพับเก็บตารางตัวแปรย่อย (Lag1-Lag5, Clay Thickness, NDBI) เพื่อให้ UI ดูสะอาดตา แต่ยังคงความโปร่งใสของข้อมูลให้ผู้ใช้สืบค้นได้

### 2. 🚨 Engineering Thresholds & Color Logic (เกณฑ์เตือนภัยทางวิศวกรรม)
ระบบวิเคราะห์และคัดกรองความเสี่ยงของแต่ละสถานีอัตโนมัติ โดยอิงจากค่าการทรุดตัวสะสม (Cumulative Subsidence) ตามหลักวิศวกรรมปฐพีกลศาสตร์:
* 🟢 **ปกติ (Stable):** ทรุดตัวสะสม 0 - 50 mm
* 🟠 **เฝ้าระวัง (Watch):** ทรุดตัวสะสม > 50 mm (พื้นที่เริ่มเข้าสู่สภาวะเสียสมดุล)
* 🔴 **เตือนภัยวิกฤต (Warning):** ทรุดตัวสะสม > 100 mm (เสี่ยงต่อความเสียหายของท่อประปาและสาธารณูปโภคขั้นรุนแรง)

### 3. 🎯 Automated Anomaly Detection (ระบบตรวจจับความผิดปกติ)
* แสดงค่าคลาดเคลื่อนสัมบูรณ์ของแต่ละสถานี (ไม่ใช่ค่าเฉลี่ย MAE) เพื่อไม่ให้สับสนกับคะแนนประเมินทั้งชุด
* แสดงคะแนนเฉลี่ย Group 5-fold CV ตาม Table 9 ของงานวิจัย: RF R² 0.45 / MAE 17.28 mm และ XGBoost R² 0.49 / MAE 16.85 mm
* **🌟 Best Fit Tag:** ติดป้ายสถานีที่แบบจำลองทำนายได้แม่นยำสูง (Error < 5 mm)
* **🚨 Worst Anomaly Tag:** ติดป้ายเตือนสถานีที่มีความคลาดเคลื่อนสูง (Error > 35 mm) เพื่อชี้เป้าให้เห็นถึงอิทธิพลของตัวแปรแฝง (Omitted Variables) เช่น น้ำหนักบรรทุกอาคาร หรือการสูบน้ำเถื่อน

### 4. 📱 Responsive UI & Academic Integration (ส่วนติดต่อผู้ใช้ที่รองรับทุกหน้าจอ)
* **Fully Responsive:** ระบบปรับขนาด Pop-up และจัดเรียงกราฟใหม่ให้เหมาะสมกับการแสดงผลบน โทรศัพท์มือถือ แท็บเล็ต และคอมพิวเตอร์ โดยอัตโนมัติ
* **Desktop station details:** เมื่อเลือกสถานีบนคอมพิวเตอร์ จะแสดงรายละเอียดในแผงด้านซ้ายที่อ่านง่ายและซูมไปยังสถานี พร้อมปุ่ม **Back to map** เพื่อคืนมุมมองเดิม; รูปแบบ pop-up บนมือถือคงเดิม
* **Floating Manual:** กล่องคู่มือที่อธิบายทฤษฎีทางวิศวกรรม (เช่น Inelastic Consolidation, Delayed Compression) และข้อจำกัดของแบบจำลอง (Concept Drift) 
* **Toggle Watermark:** ลายน้ำวิทยานิพนธ์แบบซ่อน/แสดงได้ (Toggle 'i' Button) เพื่อระบุผู้จัดทำโดยไม่บดบังแผนที่
* **Permanent Station Labels:** ป้ายชื่อสถานีโปร่งใส ลอยอยู่เหนือจุดพิกัดตลอดเวลา เพื่อการสืบค้นที่รวดเร็ว

## 📁 ไฟล์ที่ใช้ (Input / Output)

ไฟล์ใน GitHub นี้จัดเก็บเป็นชุดบีบอัด ไม่ได้วางสคริปต์ Python และ CSV แยกไว้ที่โฟลเดอร์หลัก:

| ชนิด | ชื่อไฟล์จริง | ใช้ทำอะไร |
|---|---|---|
| Random Forest | `data/Hotspot_Data_2024_RF_Group.csv` | จุดพิกัด ผล InSAR ค่าทำนาย และ SHAP ของโมเดล RF |
| XGBoost | `data/Hotspot_Data_2024_XG_Group.csv` | ข้อมูลแบบเดียวกันของโมเดล XGBoost |
| ข้อมูลบ่อ | `data/WellDATA.csv` | จับคู่รหัสสถานีและรหัสบ่อ |
| ขอบเขตจังหวัดฉบับเดิม | `Bangkok_Boundary.geojson` | ไฟล์อ้างอิงจาก `Province.zip`; ไม่แสดงกรอบนอกในแผนที่ปัจจุบัน |
| เส้นแบ่งเขต กทม. | `Bangkok_District_Boundaries.geojson` | รูปหลายเหลี่ยม 50 เขตและเส้นรอบนอกที่คำนวณจากชุดเดียวกัน; พื้นเทาโปร่งแสง เส้นแบ่งเขตสีน้ำเงินแบบประ และเส้นรอบนอกสีน้ำเงินแบบทึบหนา |
| โปรแกรมสร้างแผนที่ | `scripts/Bangkok_Hotspot_Map.py` ภายใน `scripts.zip` | รวมข้อมูล CSV และสร้าง HTML |
| หน้าเว็บที่ GitHub Pages แสดง | `index.html` | แผนที่ HTML ที่เตรียมไว้ใน repository |
| ระบบภาษา | `map-i18n.js` และ `scripts/map-i18n.js` ใน `scripts.zip` | สลับข้อความบนแผนที่ระหว่างไทยและอังกฤษ |
| ไฟล์ HTML ที่โปรแกรมสร้าง | `Bangkok_Final_Thesis_Map.html` | ผลลัพธ์ที่สร้างในโฟลเดอร์ที่เรียกโปรแกรม |

หน้าแผนที่มีปุ่ม **TH / EN** มุมขวาบน โดยค่าเริ่มต้นเป็นภาษาไทย ปุ่มนี้แปลคำอธิบาย แผงข้อมูล และข้อความในหน้าต่างสถานี; รหัสสถานี ชื่อตัวแปรวิจัย และค่าตัวเลขคงเดิม ปุ่มคู่มือย่อพอดีกับข้อความและขยายเมื่อกด ส่วน System Information & Disclaimer เปิดเป็นหน้าต่างเมื่อกดเท่านั้น ขณะเปิดจะซ่อน legend เพื่อไม่ให้ข้อความซ้อนกัน บนมือถือจะจัดคู่มือ คำอธิบาย HeatMap, Labels และแถบข้อมูลด้านล่างคนละระดับเพื่อลดการซ้อนทับ

ไฟล์ CSV มีตัวเลือก `Group`, `Random` และ `Tem` ใน `data.zip` ให้เลือกชุด RF และ XGBoost ที่ลงท้ายเหมือนกัน เช่น `_RF_Group.csv` คู่กับ `_XG_Group.csv` เพื่อเปรียบเทียบชุดข้อมูลเดียวกัน ไฟล์ Group ที่หน้าเว็บใช้เป็นผลลัพธ์ชุดล่าสุดที่ผู้ใช้ให้มา; `WellDATA.csv` เดิมยังคงใช้จับคู่รหัสสถานีและบ่อ โปรแกรมใช้ `Station_ID`, `Lat`, `Lon`, `InSAR_Normalized` (หรือ `InSAR_Normalized (mm)`), `Predicted_Subsidence` และคอลัมน์ `SHAP_*`; `WellDATA.csv` ต้องมี `Station_ID` และ `Well_ID` สำหรับจับคู่ ข้อมูล CSV ภาษาไทยที่เป็น Windows-874 จะถูกอ่านโดยโปรแกรมสำรองให้อัตโนมัติ

## 🛠️ วิธีสร้างแผนที่ (สำหรับผู้เริ่มต้น)

1. ดาวน์โหลด repository จาก GitHub แล้วแตกไฟล์ `scripts.zip` และ `data.zip` ลงในโฟลเดอร์โครงการเดียวกัน โดยคงไฟล์ในโฟลเดอร์ `scripts` และ `data` ไว้ อย่าย้าย `Bangkok_District_Boundaries.geojson` ออกจากโฟลเดอร์หลัก
2. ติดตั้ง Python 3 หากยังไม่มี จากนั้นเปิด Command Prompt หรือ Terminal ในโฟลเดอร์โครงการ แล้วตรวจสอบด้วย `py --version`
3. ติดตั้งเครื่องมือที่ต้องใช้ครั้งแรกด้วย `py -m pip install pandas folium branca numpy`
4. เปิดโปรแกรมด้วย `py scripts\Bangkok_Hotspot_Map.py`
5. ในหน้าต่างโปรแกรม เลือกไฟล์ RF, XGBoost และ `WellDATA.csv` ให้ครบ โดยเลือกคู่ RF/XGBoost ที่มีคำต่อท้ายชุดข้อมูลเหมือนกัน แล้วกด `GENERATE OFFICIAL POLICY MAP`
6. โปรแกรมสร้าง `Bangkok_Final_Thesis_Map.html` ในโฟลเดอร์ที่เปิดโปรแกรม แผนที่ที่สร้างจะแสดงพื้นสีเทาโปร่งแสง เส้นประสีน้ำเงินแบ่ง 50 เขต และเส้นรอบนอกสีน้ำเงินแบบทึบหนาจาก `Bangkok_District_Boundaries.geojson`
7. หากต้องการดูหน้าเว็บในเครื่อง ให้เปิด Command Prompt ในโฟลเดอร์หลักแล้วรัน `py -m http.server 8000` จากนั้นเปิด `http://localhost:8000/` ในเบราว์เซอร์; อย่าเปิด `index.html` ด้วยการดับเบิลคลิก เพราะเบราว์เซอร์อาจไม่อนุญาตให้หน้าเว็บอ่านไฟล์ขอบเขต

### เผยแพร่หรือแก้ไขเว็บบน GitHub

หน้าเว็บปัจจุบันคือ `index.html` ที่โฟลเดอร์หลัก ตรวจการตั้งค่า GitHub Pages แล้วพบว่าเผยแพร่จาก branch `main` โฟลเดอร์ `/(root)` และสถานะเป็น `built` ที่ URL `https://kamonwan-lab.github.io/Bangkok_Subsidence_Hotspot_Policy_Map/` การแก้ใน branch อื่นจะยังไม่ขึ้นเว็บจนกว่าจะ merge เข้า `main`; ตรวจสถานะล่าสุดได้ที่ **Settings → Pages**

1. ถ้าสร้างแผนที่ใหม่ ให้นำ `Bangkok_Final_Thesis_Map.html` ไปแทนชื่อ `index.html` ในโฟลเดอร์หลัก และเก็บ `Bangkok_District_Boundaries.geojson` ไว้ข้างกัน เพราะแผนที่โหลดเส้นแบ่งเขตจากไฟล์นี้
2. บนหน้า repository เลือก **Add file → Upload files** แล้วอัปโหลดไฟล์ที่แก้ (หรือเปิดไฟล์แล้วกดไอคอนดินสอสำหรับการแก้ข้อความเล็กน้อย) จากนั้นกด **Commit changes** ถ้าแก้ `index.html` อย่าลืมอัปโหลด `map-i18n.js` ไว้ในโฟลเดอร์หลักด้วย เพื่อให้ปุ่ม TH / EN ทำงาน การแก้ไฟล์บน `main` จะเผยแพร่ได้เมื่อ Settings → Pages ตั้ง Source เป็น branch `main` และโฟลเดอร์ `/(root)`; หากไม่แน่ใจให้ตรวจหน้านั้นก่อน
3. เปิด URL เว็บอีกครั้งหลังการเผยแพร่เสร็จ หากไม่เปลี่ยนให้ลองรีเฟรชแบบล้างสำเนาเดิมด้วย `Ctrl+F5`

### กรณีแจ้งว่า API หมดอายุ

ในโค้ดไม่มี API key หรือ token ให้ต่ออายุ แต่ภาพแผนที่ CARTO เดิมแสดงข้อความ `API KEY REQUIRED` ระหว่างตรวจเว็บ จึงเปลี่ยนแผนที่ฐานเป็นแผ่นที่ OpenStreetMap ซึ่งใช้ได้โดยไม่ต้องใช้ key และมีเครดิตผู้ให้ข้อมูลแสดงบนแผนที่ หากภาพแผนที่ยังไม่ขึ้น ให้ตรวจอินเทอร์เน็ตและลองเปิดเว็บใหม่ หากมีข้อความผิดพลาดจาก API อื่น ให้ส่งชื่อบริการและภาพข้อความผิดพลาดโดยปิดบัง token ก่อน อย่าวางรหัสลับใน `index.html` เพราะทุกคนที่เปิดหน้าเว็บจะเห็นได้

### ขอบเขตกรุงเทพฯ และรายการตรวจงานวิจัย

`Bangkok_Boundary.geojson` มาจากขอบเขตจังหวัดใน `Province.zip` และเก็บไว้เป็นไฟล์อ้างอิงเดิม แผนที่ปัจจุบันใช้ `Bangkok_District_Boundaries.geojson` ซึ่งแปลงจาก `Amphoe_เขต+กทม.shp` ในชุดข้อมูลเขตกรุงเทพฯ เป็นพิกัด WGS 84 มีรูปหลายเหลี่ยม 50 เขต และเส้นรอบนอกที่คำนวณจากขอบเขตรายเขต โดยแสดงพื้นสีเทาโปร่งแสง เส้นประสีน้ำเงินภายใน และเส้นทึบสีน้ำเงินหนาที่ขอบนอก

ในไฟล์ที่ติดตามอยู่ใน repository ปัจจุบันไม่พบรายการ TODO หรือ tab/ไฟล์สำหรับงานตีพิมพ์วิจัย จึงยังยืนยันไม่ได้ว่ารายการในส่วนนั้นทำครบหรือไม่
